SECURITY ARCHITECTURE

Cryptographic Pipeline

01 · SALT

Unique Salt

A random 16-byte salt is generated per file so identical passwords never generate identical keys.

02 · DERIVE

Key Derivation

PBKDF2-HMAC-SHA256 stretches your password through 390,000 iterations into a 256-bit key.

03 · SEAL

Fernet Encryption

AES-128-CBC encryption combined with an HMAC-SHA256 authentication tag guarantees integrity.

04 · VERIFY

SHA-256 Audit

Cryptographic checksums are recorded before and after processing to prove zero data corruption.
